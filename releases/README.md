# TimeMachine VSIX releases

Run `npm run vsix` from the repository root to build the current package: **timemachine-1.5.0.vsix**.

In VS Code, open **Extensions → … → Install from VSIX**, choose the package, and reload. The 1.5.0 release includes sidebar time ranges and daily totals, local JSON/CSV reports, command-copy actions, and project folder names in older opening entries.

See [publishing instructions](../PUBLISHING.md) for Marketplace upload and [the launch kit](../marketing/launch-plan.md) for GitHub assets. VSIX files are generated artifacts and are ignored by Git; attach the package to a GitHub release when publishing it.
